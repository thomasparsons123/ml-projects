# ML Projects

A collection of my machine learning projects, built while learning ML from
the ground up (Python, scikit-learn, and beyond).

## Projects

- **[Titanic Survival](./Titanic)** — logistic regression predicting passenger
  survival. ~81% test accuracy. Covers the full pipeline: data cleaning,
  train/test split, training, and evaluation.

- **[Logistic Regression from Scratch](./LogisticRegression)** — the full
  classifier (sigmoid, gradient descent, log loss) implemented by hand with NumPy,
  no scikit-learn. Demonstrates the internals of what a library call actually does.

*More projects coming as I work through neural networks, deep learning, and more.*
